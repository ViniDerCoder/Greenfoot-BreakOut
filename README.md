# Greenfoot Breakout

This is a classic arcade game implemented using Greenfoot, a Java framework for creating interactive games and simulations. In this breakout game, the player controls a paddle to bounce a ball and break bricks.

## Features

- Intuitive controls: Use the arrow keys to move the paddle left and right.
- Multiple levels: The game consists of multiple levels with increasing difficulty.
- Special bricks: Some bricks have more lifes than others.

## Installation

1. Clone the repository: `git clone https://github.com/ViniDerCoder/Greenfoot-BreakOut.git`
2. Open the project in [Greenfoot](https://www.greenfoot.org/download).
3. Compile and run. It should start the correct world automatically.

## How to Play

1. Use the left and right arrow keys to move the paddle.
2. Bounce the ball off the paddle to break the bricks.
3. Avoid letting the ball fall off the bottom of the screen.
4. Clear all the bricks to advance to the next level.
